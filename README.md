# planejAI 🚀

Bem-vindo ao **planejAI**! Esta é uma aplicação web moderna, construída com foco em alta performance e em uma excelente experiência de desenvolvimento e de usuário.

## 🔗 Acesso Rápido

**Deploy em Produção:** [planej-ai-five.vercel.app](https://planej-ai-five.vercel.app)

***

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes ferramentas e tecnologias:

- **[React](https://react.dev/)**: Biblioteca JavaScript para criação de interfaces de usuário.
- **[TypeScript](https://www.typescriptlang.org/)**: Superset do JavaScript que adiciona tipagem estática ao código.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build super rápida para projetos web modernos.
- **ESLint**: Ferramenta de linting configurada para garantir a qualidade e padronização do código.

***

## 🚀 Como executar o projeto localmente

Siga as instruções abaixo para rodar o projeto na sua máquina de desenvolvimento.

### Pré-requisitos

Você precisará ter o [Node.js](https://nodejs.org/) (versão 18+ recomendada) e um gerenciador de pacotes instalado, como **npm**, **yarn**, **pnpm** ou **bun**.

### Passo a passo

1. Clone este repositório:

```bash
git clone https://github.com/gabrieelsza/planejAI.git
```

2. Acesse a pasta do projeto:

```bash
cd planejAI
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Abra o navegador e acesse `http://localhost:5173` ou a porta indicada pelo Vite no terminal.

***

## 📜 Scripts Úteis

No diretório do projeto, você pode utilizar os seguintes comandos:

- `npm run dev`: Inicia a aplicação em modo de desenvolvimento com Hot Module Replacement (HMR).
- `npm run build`: Compila a aplicação e gera os arquivos estáticos otimizados para produção na pasta `dist`.
- `npm run lint`: Executa o ESLint para identificar problemas de código.
- `npm run preview`: Inicia um servidor local para visualizar a versão de produção.
